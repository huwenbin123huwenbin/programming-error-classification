## 二、ScholarOne 投稿步骤

### 1. 进入系统
- 访问：https://mc.manuscriptcentral.com/toce
- 使用已有账号登录，或注册新账号（用西京学院/个人邮箱，勿用学生邮箱）

### 2. 开始新投稿
- 点击 **"Author Center"** → **"Start New Submission"**
- 稿件类型选 **"Research Article"**（或 "Full Paper"）

### 3. 填写稿件信息（Step 1–4）
- **Title**：复制上面的完整标题（含副标题）
- **Abstract**：复制 `paper_acm.tex` 中 abstract 区（Context/Objective/Method/Results/Conclusions 结构化，209词）
- **Keywords**：programming verdict classification, machine learning, large language models, competitive programming, Codeforces, metadata-based classification
- **Subject Area**：Computing Education / Educational Data Mining

### 4. 上传文件（Step 5 — File Upload）
按顺序上传：
1. **Main Document**（盲审版）→ 上传 `paper_acm.pdf`
2. **Cover Letter** → 上传 `Cover_Letter.pdf`
3. **Highlights** → 上传 `Highlights.pdf`
> 注：若期刊要求盲审，需另存一份去作者信息的 PDF；当前 `paper_acm.pdf` 含作者信息，投稿时选 "Main Document" 即可（TOCE 通常为双盲，但 ACM 允许带名提交，以系统要求为准）

### 5. 作者信息（Step 6）
- 确认 Corresponding Author = Wenbin Hu
- Affiliation：School of Computer Science, Xijing University, Xi'an, China
- ORCID（如有）

### 6. 推荐审稿人（Step 7 — Reviewer Suggestions）
- 填入上方5位推荐审稿人姓名 + 单位 + 邮箱（邮箱从各人主页/Google Scholar 获取）
- 同时可填 **排除审稿人**（Exclude，如存在竞争关系者）

### 7. 确认并提交（Step 8）
- 下载 **PDF Proof** 通读一遍，确认图表/参考文献无误
- 勾选伦理声明、原创性声明、版权授权
- 点击 **"Submit"**
