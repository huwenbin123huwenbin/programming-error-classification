# Deprecated — superseded by the authoritative pipeline

Files here are kept only for provenance. **Do not cite their numbers.**

## experiment_code/deprecated/

- `user_disjoint_replication.py`, `user_disjoint_results.json`
  Ran the submitter-disjoint replication under the deprecated feature set
  (constant `hour=12`, leaky `user_success_rate`) and `RandomForestClassifier(n_estimators=200)`.
  Produces GB 92.15% test / 95.06% CV — **not** the paper's figures.
  Superseded by `experiment_code/user_disjoint_replication_v3.py`, which repeats the
  same GroupShuffleSplit (random_state=42, zero user overlap, 10,900/2,460) under the
  six authoritative features and reproduces the paper exactly:
  GB 93.13% (CV 92.15%), RF 91.99%, LR 87.15%; GB per-class F1
  CE 0.788, TLE 1.000, MLE 0.988, WA 0.957, RE 0.256.
  Result artifact: `experiment_code/user_disjoint_results_v3.json`.

## llm_experiments/deprecated/

- `mcnemar_results.json` — old-system pairwise tests (GB accuracy 95.02%, the
  deprecated 7-feature model). The paper's McNemar table is regenerated by
  `experiment_code/audit_llm_numbers.py` from the fair-rerun prediction files.
- `gb_metrics_true.json` — old-system GB metrics (accuracy 95.02%, per-class F1
  CE 0.897). The paper's GB numbers come from
  `experiment_results/authoritative_results_v3.json`.
- `deepseek_results.json` — early single-item run (17.37% accuracy); superseded by
  the fair-rerun and zero-shot-full runs in `llm_experiments/`.
